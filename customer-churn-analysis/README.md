# Customer Churn Analysis

## Objective
Analyze customer data to understand churn behavior and identify factors that contribute to customer attrition.

## Tools Used
- Python (pandas, matplotlib)
- SQL
- Power BI

## Key Questions
- What percentage of customers churned?
- Which customer segments have higher churn?
- What factors are associated with churn?
